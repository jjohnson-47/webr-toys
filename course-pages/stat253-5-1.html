5.1: Continuous Probability Distributions

STAT A253 - University of Alaska Anchorage | Summer 2025

From Discrete to Continuous Random Variables

In previous chapters, we focused on discrete random variables, where outcomes are countable (e.g., the number of heads in three coin flips). For these variables, we can assign a specific probability to each individual outcome.

Now, we turn to continuous random variables, which can take on an infinite number of values within a given range. Think of measurements common in the sciences, like height, weight, time, or temperature. It doesn't make sense to talk about the probability of a salmon weighing exactly 3.5000... kg. Instead, we talk about the probability of its weight falling within an interval, such as between 3.4 kg and 3.6 kg.

The Probability Density Function (PDF)

As the video explained, the probability distribution of a continuous random variable x is described by a smooth curve called a probability density function, or f(x). This curve is a model for the shape of the data's distribution. The single most important idea is:

For a continuous variable, probability is represented by the area under the PDF curve.

Key Properties of a Continuous Probability Distribution

  1. Area Equals Probability: The probability that x falls between two values, a and b, is the area under the curve f(x) between those points.
  2. Total Area is 1: The total area under the entire PDF curve must always equal 1.
  3. Probability of a Single Point is Zero: The area above a single point has zero width, and therefore zero area. This means P(x = a) = 0.
  4. Endpoints Don't Affect Probability: As a result of the previous point, including or excluding the endpoints of an interval does not change the probability. Therefore, P(a < x < b) = P(a ≤ x ≤ b).

Step 2: Calculate the Area Using Geometry

For simple shapes like this triangle, we can use basic geometry:

  • Base of the triangle = 10 - 5 = 5
  • Height of the triangle = 0.2 (peak of the triangle)

Area = ½ × base × height = ½ × 5 × 0.2 = 0.5

Therefore, there is a 50% probability that the friction coefficient is less than 10.

Beyond Geometry: How R Calculates Area

Most PDFs are not simple geometric shapes. The formal way to find the area under a curve is with calculus (integration). While you are not required to do this by hand, it's useful to see how R would tackle this problem numerically using the integrate() function.

The R code behind our interactive tool:


# First, we define the triangular PDF as a function in R
triangular_pdf <- function(x) {
  # This uses ifelse() for a compact, "vectorized" definition
  ifelse(x >= 5 & x < 10, 0.04 * (x - 5),
    ifelse(x >= 10 & x <= 15, -0.04 * (x - 15), 0)
  )
}

# Now, use the integrate() function to find the area under our PDF
# from the lower limit of 5 to the upper limit of 10.
result <- integrate(triangular_pdf, lower = 5, upper = 10)

# Print the result
print(result)

R Output: 0.5 with absolute error < 5.6e-15

The result, 0.5, perfectly matches our geometric calculation!

🎯 Key Takeaways

  • Continuous variables represent measurements that can take infinite values in a range
  • Probability = Area under the PDF curve between two points
  • Total area under any PDF must equal 1
  • R's integrate() function can calculate areas for any PDF shape
  • Interactive tools help visualize and verify calculations

Looking Ahead

For the common probability distributions we will study next (like the Uniform and Normal distributions), you will not need to perform calculations with geometry or calculus. R provides convenient, built-in functions (like punif() and pnorm()) that make finding these probabilities easy.
